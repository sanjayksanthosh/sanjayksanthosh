# Hi, I'm Sanjay 👋

Full-stack developer who builds **complete products** — auth, persistence, admin

## What I build

  offline queues and real business workflows.
- **React / Next.js** front ends with TypeScript, Tailwind and charting.
- **Django & Node.js** back ends with scraping, ML pipelines and payment
  integrations.
